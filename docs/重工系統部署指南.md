## 🛠️ 部署步驟

### 1. 資料庫部署

```bash
# 1.1 連接到您的SQL Server資料庫
# 1.2 執行重工表建立腳本
sqlcmd -S localhost\SQLEXPRESS -d 品保資料庫 -i create_rework_tables.sql
```

**腳本會建立以下資料表：**
- `重工申請單` - 重工申請主檔
- `重工執行記錄` - 執行過程記錄
- `重工品檢記錄` - 品檢結果記錄  
- `重工成本分析` - 成本分析資料
- `重工效益評估` - 效益評估記錄

### 2. 後端部署

```bash

pip install flask flask-cors pyodbc pandas numpy openpyxl jwt
```

## 🔄 系統整合流程

### NCMR 轉重工流程
1. 在不合格品管理頁面判定為「重工」
2. 點擊「轉重工申請」按鈕
3. 自動跳轉到重工管理頁面並帶入NCMR ID
4. 填寫重工申請資料並提交
5. 系統自動更新NCMR狀態為「轉重工」

### 審核流程
1. 重工申請提交後狀態為「申請中」
2. 有權限人員可進行審核（核准/拒絕）
3. 核准後狀態變為「已核准」，可開始執行
4. 拒絕後狀態變為「已拒絕」

### 執行流程
1. 審核通過後可開始執行重工
2. 記錄執行過程和相關資訊
3. 進行品檢驗證
4. 記錄相關成本
5. 完成後狀態變為「已完成」

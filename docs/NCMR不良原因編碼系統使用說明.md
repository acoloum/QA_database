# NCMR 不良原因編碼系統使用說明

## 📋 功能概述

已為您的 NCMR(不合格品管理)系統新增「不良原因編碼」功能,採用鋁擠型產業專用的分類系統。

---

## 🔧 修改內容

### 1. 資料庫變更
已新增兩個欄位到「不合格品單」表:
- `不良原因大類` (NVARCHAR(10)) - 儲存大類代碼 (M, E, D, H, T, P, Q, O)
- `不良原因細項` (NVARCHAR(100)) - 儲存完整編碼 (例: E-01: 擠型溫度不當)

**執行步驟:**
1. 開啟 SQL Server Management Studio
2. 執行檔案: `add_defect_reason_columns.sql`
3. 確認兩個欄位新增成功

---

### 2. 後端 API 修改 (app.py)

#### 新增 API 端點:
- `POST /api/ncmr/update` - 更新 NCMR 記錄 (原本缺少)

#### 修改 API 端點:
- `POST /api/ncmr/add` - 新增時支援不良原因欄位

---

### 3. 前端介面修改 (ncmr.html)

#### 新增表單欄位:
在「新增/編輯異常單」視窗中,新增兩層式下拉選單:
1. **不良原因大類** - 8 大類選項
2. **不良原因細項** - 根據大類動態載入

#### 新增 JavaScript 功能:
- `updateDefectReasons()` - 大類選擇後自動更新細項選單
- `defectReasons` - 完整的不良原因資料結構

#### 表格顯示:
新增「不良原因」欄位,以藍色 badge 顯示編碼 (例: E-01)

## 📖 使用方式

### 新增異常單時:
1. 點擊「新增異常單」按鈕
2. 填寫基本資訊
3. 選擇「不良原因大類」(例: E - 擠型製程)
4. 系統自動載入該大類的細項選單
5. 選擇「不良原因細項」(例: E-01: 擠型溫度不當)
6. 儲存

### 編輯異常單時:
1. 點擊「編輯」按鈕
2. 已儲存的不良原因會自動載入
3. 可修改大類或細項
4. 儲存更新

### 查看報表:
- 表格中「不良原因」欄位以藍色標籤顯示編碼
- 可按編碼排序、篩選
- 便於統計分析

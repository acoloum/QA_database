## 🚀 系統測試步驟

### 1. 確認服務運行
Flask服務應該已經運行在：
- http://127.0.0.1:5000
- http://192.168.0.144:5000

### 2. 測試前端連線
1. 開啟瀏覽器訪問 `index.html`
2. 使用現有帳號登入系統
3. 應該看到新的「重工管理」選單

### 3. 測試重工功能
**步驟A：建立測試NCMR**
1. 進入「不合格品」頁面
2. 點擊「新增異常單」
3. 填寫基本資料
4. **判定結果**選擇「重工」
5. 儲存後點擊「轉重工申請」

**步驟B：直接測試重工功能**
1. 進入「重工管理」頁面
2. 點擊「新增申請」
3. 手動輸入NCMR單號
4. 填寫申請資料並提交

### 4. 驗證API功能
可以使用瀏覽器開發者工具檢查以下API：
- `GET /api/inspectors` - 獲取檢驗人員列表
- `GET /api/rework/applications` - 獲取重工申請列表
- `GET /api/rework/statistics` - 獲取統計數據

## 🔧 常見問題解決

### 問題1：登入後頁面空白
**解決方案：**
- 檢查瀏覽器開發者工具(F12)的Console標籤
- 查看是否有JavaScript錯誤
- 確認Token是否正確儲存

### 問題2：API返回404或500錯誤
**解決方案：**
- 確認Flask服務是否正常運行
- 檢查API路徑是否正確
- 查看服務端日誌輸出

### 問題3：資料庫連線錯誤
**解決方案：**
- 確認SQL Server服務正在運行
- 檢查連線字串中的伺服器名稱
- 確認資料庫名稱是否正確

### 問題4：權限錯誤401
**解決方案：**
- 確認使用者已正確登入
- 檢查Token是否過期
- 重新登入獲取新Token

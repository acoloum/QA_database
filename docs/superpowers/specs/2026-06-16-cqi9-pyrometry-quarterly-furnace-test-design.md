# CQI-9 每季爐溫測試紀錄模組 — 設計規格

- 日期：2026-06-16
- 模組代稱：爐溫測試（Pyrometry）
- 適用標準：CQI-9 熱處理特殊製程評估（高溫測量 / Pyrometry）

---

## 1. 目的與範圍

為符合 CQI-9 條文要求，在 QMS 中新增「爐溫測試」模組，記錄並管理每台爐子的定期高溫測量：

- **TUS（溫度均勻性測試 / Temperature Uniformity Survey）**：在有效加熱區放置多支熱電偶，量測各位置在設定溫度下的溫度偏差與全爐均勻度。每季執行。
- **SAT（系統精度測試 / System Accuracy Test）**：用校正過的測試儀器與爐子本身控溫/記錄系統比對，確認系統讀值誤差在允許範圍。各控溫區各一筆。

TUS 與 SAT 整合在同一模組，以「測試類型」區分。

### 納管設備（5 台爐）

| 爐子 | 製程類型 | TUS 點數 | SAT 點數 |
|---|---|---|---|
| T6 爐 ×2 | 時效 | 12 | 各 2 |
| T4 爐 ×1 | — | 12 | 4 |
| 退火爐 A | 退火 | 12 | 4 |
| 退火爐 B | 退火 | 12 | 6 |

TUS 每爐固定 12 點；SAT 點數（控溫區數）因爐而異，設定於設備主檔。

### 本次範圍（功能）

納入：
- 設備主檔管理（A）下次應測日 + 到期提醒、（B）總覽看板、（D）報告匯出 PDF/Excel、（E）單台爐歷年趨勢
- TUS 上傳時間序列資料檔，自動繪曲線並回填量測點摘要與判定
- 附件依「用途」分類，支援「測試儀器數據」與「爐體記錄數據」雙來源疊圖比對

不納入（YAGNI，日後可加）：
- 不合格自動連動 NCMR / CAPA（功能 C）

## 4. 判定邏輯

- 每個量測點：`|偏差| ≤ 允許公差` → 該點合格。
  - TUS 偏差 = 量測溫度（最高溫 / 最低溫）對設定溫度之差，取絕對值最大者為該點最大偏差。
  - SAT 偏差 = `校正測試儀表讀值 − 控制儀表讀值`（或加修正值後）對允許誤差比較。
- 全部點合格 → 該筆測試「合格」；任一點超出 → 「不合格」並標紅。
- TUS 另算「均勻度極差 = 全爐最高溫 − 全爐最低溫」、最大正/負偏差。
- 判定基準一律以「測試儀器數據」為準；爐體數據僅作對照。

## 5. 自動繪圖（TUS）

1. 使用者上傳「測試儀器數據」CSV/Excel（**格式固定**：第一欄為時間，其後每欄為一支熱電偶溫度）。
2. 後端用 pandas 解析時間序列，回傳各通道資料與每點最高/最低溫。
3. 自動回填 TUS 量測點明細（最高溫、最低溫、最大偏差、合格），使用者可手動覆寫。
4. 前端用 chart.js 畫多通道曲線，標示合格區間（設定溫度 ± 公差）。
5. （選配）上傳「爐體記錄數據」→ 以虛線疊在同圖比對；SAT 若兩組皆上傳，可自動帶各區差值。

## 6. 頁面與操作流程

放在左側選單「爐溫測試 (CQI-9)」群組下。

### 6.1 總覽看板 `/pyrometry`（功能 B）
5 台爐卡片，顯示最近一次 TUS/SAT 結果（合格綠 / 不合格紅）、下次應測日、到期狀態徽章（🟢 正常 / 🟡 即將到期 / 🔴 逾期，逾期置頂）。點卡片進該爐紀錄。

### 6.2 測試紀錄列表 `/pyrometry/tests`
篩選：爐子 / 類型（TUS|SAT）/ 季別 / 合格狀態 / 日期區間。每列：爐號、類型、季別、日期、判定、人員。提供新增 / 檢視 / 編輯 / 刪除。

### 6.3 測試新增 / 明細頁
選爐子 → 類型 → 自動帶出點數與公差 → 填主檔 → 量測點表格（TUS 12 列 / SAT 2·4·6 列）→ 上傳數據（自動繪圖 + 回填）→ 即時顯示判定 → 附件區與曲線圖 → 存檔。含「匯出報告」按鈕（功能 D）。

**TUS 新增 6 步流程：**
1. 選爐子 + 類型 TUS → 自動帶出 12 點、公差、季別
2. 填設定溫度、日期、人員、儀器資訊
3. 上傳「測試儀器數據」CSV → 自動畫曲線 + 回填 12 點
4. （選配）上傳「爐體記錄數據」→ 疊圖對照
5. 系統即時顯示均勻度極差、最大偏差、合格/不合格
6. 存檔 → 自動更新該爐「下次應測日 = 本次日期 + TUS頻率」

### 6.4 設備主檔管理 `/pyrometry/furnaces`
5 台爐 CRUD。點單台爐 → 歷年趨勢圖（功能 E：均勻度 / 最大偏差隨時間）。

## 7. 功能細節

- **下次應測日（功能 A）**：`下次應測日 = 該爐該類型最近一次測試日期 + 頻率(月)`。到期狀態：距今 ≤ 14 天 → 即將到期（🟡）；已過期 → 逾期（🔴）。
- **報告匯出（功能 D）**：單筆測試匯出，含主檔資訊、量測點摘要表、曲線圖、附件清單。沿用既有 openpyxl 匯出方式（Excel）；PDF 視既有工具評估。
- **歷年趨勢（功能 E）**：單台爐歷次 TUS 的均勻度極差 / 最大偏差折線圖。

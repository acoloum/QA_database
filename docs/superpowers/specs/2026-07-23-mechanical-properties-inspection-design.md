# 機械性質檢驗模組 — 設計文件

- 日期：2026-07-23
- 方案：A（沿用全站模組模式：儀表板 + 清單 + 登錄表單）
- 對象：鋁擠型熱處理後之機械性質檢驗（安泰 6061-T651 等）

---

## 1. 背景與目的

目前機械性質檢驗數據以 Excel 維護（`必榮數據(機械性質)2026.xlsx`）：

- **每個工作表 = 一個產品尺寸**（外徑×內徑，如 `36x25.2`、`43x35.7`…共 25 個尺寸）。
- 表格為**轉置**格式：每一「欄」是一筆測試紀錄（依測試日期），每一「列」是一個欄位。
- 所有工作表列結構一致（28–29 列固定欄位），欄數差異僅代表測試筆數不同。

一筆完整測試紀錄包含：

- **基本資料**：測試日期、擠製日期/批號、T4爐具編號、T4溫度/時間（如 `530/40MIN`）、T6溫度/時間（如 `175/6HR`）、備註。
- **5 項機械性質**，每項在 **2 個位置 × 2 個取樣（共 4 值）** 量測：
  - EC 導電度（無規格）
  - 硬度（~70，Webster HW）
  - 抗拉強度（~400 MPa）
  - 降伏強度（~380 MPa）
  - 伸長率（~12%）
  - 位置命名：`爐門`（1-1、1-2）、`爐頂`（2-1、2-2）。

**目標**：在既有 QC 系統中新增「機械性質檢驗」模組，取代 Excel 手動維護，並提供查詢、SPC 分析、Excel 匯入、匯出/列印報告。

## 2. 需求摘要

| 需求 | 說明 |
|---|---|
| 資料登錄 + 查詢 | 現場在系統中新增/編輯每筆測試，依尺寸/材質/日期查詢歷史 |
| 趨勢 / SPC 分析 | 對硬度/抗拉/降伏/伸長率做管制圖、趨勢、Cpk，接現有 SPC 引擎 |
| 匯入現有 Excel | 上傳既有多工作表 Excel，自動解析為資料庫紀錄 |
| 匯出 / 列印報告 | 匯出成貼近原 Excel 的報表格式 |

**規格判定規則**：

- 規格依**合金/回火狀態**（如 6061-T651）。
- 規格值**直接讀取現有「廠商公差」資料**（依 材質 + 產品尺寸 撈取），不建獨立規格表。
- **機械性質為單邊規格：只有下限、沒有上限**。NG 判定 = `量測值 < 下限`。
- **EC 導電度無規格**，不判定；介面上預設隱藏、需要時展開。
- 目前廠商公差中安泰 6061-T651 的機械性質項目**上下限尚為空值**；在填入前，判定顯示「無規格」，不阻擋開發。

## 3. 資料模型

新增 2 張表，沿用專案以中文命名 `__tablename__` 的慣例。

### 3.1 `機械性質檢驗`（主檔）

一筆 = Excel 裡的一「欄」測試紀錄。

| 欄位（中文名） | 型別 | 說明 |
|---|---|---|
| 識別碼 | Integer PK | |
| 產品尺寸 | String | 如 `36x25.2`，對應廠商公差的「規格」 |
| 材質 | String | 如 `6061-T651`（合金/回火） |
| 廠商ID | Integer FK → 廠商資料（可空） | 供規格撈取，如 安泰 |
| 測試日期 | Date | |
| 擠製日期批號 | String | 可含多批（多行文字） |
| T4爐具編號 | String | |
| T4溫度時間 | String | 如 `530/40MIN` |
| T6溫度時間 | String | 如 `175/6HR` |
| 備註 | String | |
| 是否NG | Boolean | 存檔時計算：任一量測值低於下限即為 True |
| 建立日期 / 建立者ID / 更新日期 | — | 沿用專案稽核欄位慣例 |

（是否採軟刪除 `SoftDeleteMixin` 於實作時對齊 NCMR/客訴等既有表決定。）

### 3.2 `機械性質量測明細`（子檔）

一列 = 一個量測值，沿用 `ShippingMeasurement` 模式（含 SPC 離群值處理欄位）。

| 欄位（中文名） | 型別 | 說明 |
|---|---|---|
| 識別碼 | Integer PK | |
| 機械性質檢驗_ID | Integer FK → 機械性質檢驗 | |
| 量測項目 | String | `EC值` / `硬度` / `抗拉強度` / `降伏強度` / `伸長率` |
| 測量位置 | String | `爐門` / `爐頂` |
| 取樣序 | Integer | 1 / 2 |
| 量測值 | Numeric(12,4) | 可空（未量測） |
| 下限 | Numeric(12,4) | 存檔時從規格快照（EC 為空） |
| 是否超差 | Boolean | `量測值 < 下限` 為 True；無下限則 False |
| 排除統計 | Boolean | SPC 離群值標示（沿用 ShippingMeasurement） |
| 排除原因 / 排除者ID / 排除時間 | — | 同上 |

- 唯一鍵：（機械性質檢驗_ID, 量測項目, 測量位置, 取樣序）。
- **取樣原則**：常態每項只取 **取樣序 1**（爐門1-1、爐頂2-1，共 2 值）；該批數值異常/複測時才加測 **取樣序 2**（1-2、2-2），最多 4 值/項。取樣序 2 的量測值常態為空。
- 一筆測試對應 5 項 ×（2 位置 × 最多 2 取樣）= 最多 20 列，常態約 8–10 列有值（EC 可全空）。
- **上限欄位不設**（單邊規格）；若日後需要再擴充。

## 4. 規格判定

1. 登錄/存檔時，依（材質 + 產品尺寸）到 **廠商公差**（`廠商公差主檔` / `廠商公差明細檔`）撈取對應明細。
2. 取硬度/抗拉/降伏/伸長率的**下限**（廠商公差的「公差下限」或「標準值」，實作時確認欄位），快照寫入量測明細的「下限」。
3. `是否超差 = 量測值 < 下限`；主檔「是否NG」= 任一明細超差。
4. EC 值不撈規格、不判定。
5. 查無規格或下限為空 → 該項不判定（`是否超差 = False`，介面顯示「—/無規格」）。

**項目名稱對應（已定案）** — 機械性質項目 → 廠商公差明細「測量項目」：

| 機械性質項目 | 廠商公差項目 | 單位 |
|---|---|---|
| 硬度 | 洛氏硬度 | HRB |
| 抗拉強度 | 抗拉強度 | MPa |
| 降伏強度 | 降伏強度 | MPa |
| 伸長率 | 伸長率 | % |
| EC值 | （無規格，不對應） | — |

映射以常數/設定表實作，方便日後調整。

## 8. Excel 匯入 / 匯出（Phase 2）

**匯入**：解析既有多工作表轉置格式。

- 逐工作表：工作表名 → 產品尺寸；材質預設 `6061-T651`（可於匯入介面調整）。
- 逐欄（每欄一筆測試）：讀測試日期、批號、T4/T6、備註；讀 5 性質 × 爐門/爐頂 × 2 取樣 = 20 值。
- 略過空白欄與非資料工作表（如 `工作表1`）。
- 匯入時套規格計算 NG。

**匯出**：以 openpyxl 產生貼近原格式的轉置報表（可先做單一尺寸/區間匯出）。

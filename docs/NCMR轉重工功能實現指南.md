## 🚀 測試步驟

### 步驟1：建立測試NCMR
1. 進入「不合格品」頁面
2. 點擊「新增異常單」
3. 填寫測試資料：
   - 來源：巡檢/出貨檢/客訴/進料
   - 產品資訊：測試產品
   - 批號：TEST001
   - 不合格數量：100
   - 不良描述：尺寸偏差需要重工
   - **判定結果選擇「重工」**
4. 保存NCMR

### 步驟2：轉重工申請
1. 在NCMR列表中找到剛才建立的記錄
2. 點擊「處置」按鈕
3. 點擊「轉重工申請」

### 步驟3：驗證自動填寫
1. **檢查單號**：應該看到正確的NCMR ID
2. **檢查產品資訊**：應該自動填入「測試產品」
3. **檢查批號**：應該自動填入「TEST001」
4. **檢查部門**：應該顯示相關廠商資訊
5. **檢查申請原因**：應該包含NCMR的不良描述
6. **檢查重工數量**：應該是100

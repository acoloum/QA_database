### 資料庫驗證
```sql
-- 檢查主檔資料
SELECT * FROM dbo.廠商公差主檔

-- 檢查明細資料
SELECT * FROM dbo.廠商公差明細檔

-- 檢查關聯
SELECT 
    M.識別碼,
    M.材質,
    M.規格,
    V.廠商名稱,
    D.測量項目,
    D.公差下限,
    D.公差上限
FROM dbo.廠商公差主檔 M
LEFT JOIN dbo.廠商資料 V ON M.廠商ID = V.識別碼
LEFT JOIN dbo.廠商公差明細檔 D ON M.識別碼 = D.主檔ID
```

## ⚠️ 常見問題

### 問題 1: 資料庫表格創建失敗
**錯誤訊息**: `FOREIGN KEY constraint failed`
**解決方案**: 
- 確認 `dbo.廠商資料` 和 `dbo.品管人員` 表格已存在
- 確認欄位名稱和類型匹配

### 問題 2: API 調用返回 401
**錯誤訊息**: `認證失效，請重新登入`
**解決方案**:
- 重新登入系統
- 確認 Token 儲存在 localStorage
- 檢查 Token 是否過期 (24小時)

### 問題 3: 新增資料時提示"找不到廠商"
**錯誤訊息**: `廠商ID 必須在 dbo.廠商資料 中存在`
**解決方案**:
- 先在系統中新增廠商資料
- 或在新增公差時不選擇廠商（可為空）

### 問題 4: 匯入 Excel 失敗
**錯誤訊息**: `檔案讀取失敗`
**解決方案**:
- 確認 Excel 格式正確 (.xlsx 或 .xls)
- 確認欄位名稱與說明文件一致
- 確認廠商名稱在資料庫中存在

## 🎨 技術原理

### 問題根因
Bootstrap Modal在某些情況下會：
1. 沒有正確移除 `.modal-backdrop` 元素
2. 沒有重置 `body.modal-open` 類
3. 保留 `overflow: hidden` 樣式

### 解決方案
1. **主動清理**：每次開啟前清理舊元素
2. **事件監聽**：監聽hidden事件確保清理
3. **配置優化**：正確的Modal初始化參數
4. **快速鍵支持**：ESC鍵緊急清理

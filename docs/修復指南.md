# 修復NCMR轉重工問題的解決方案

## 🎯 問題分析

從日誌中看到兩個核心問題：

1. **前端NCMR_ID為None**：
   - 前端表單提交時`document.getElementById('ncmrId').value`為空
   - `parseInt()`空字符串返回`NaN`
   - 後端收到`null`或`undefined`

2. **SQL Server中文字元編碼問題**：
   - 錯誤：`將 nvarchar 值 '安泰' 轉換成資料類型 int 時，轉換失敗`
   - 這表明資料庫連線編碼有問題

## 🔧 臨時解決方案

### 1. 手動測試功能

**步驟A：手動輸入NCMR ID**
1. 開啟重工管理頁面
2. 點擊「新增申請」
3. **手動輸入NCMR ID（如：1）**
4. 填寫其他必要資訊
5. 提交申請

**步驟B：測試NCMR API**
在瀏覽器控制台執行：
```javascript
fetch('/api/ncmr/1', {headers: getHeaders()})
  .then(res => res.json())
  .then(data => console.log('NCMR數據:', data))
  .catch(err => console.error('API錯誤:', err));
```

### 2. 檢查現有NCMR數據

在SQL Server Management Studio中執行：
```sql
SELECT 識別碼, 日期, 廠商, 產品資訊, 批號, 不良描述 
FROM dbo.不合格品單 
WHERE 識別碼 = 1
```
